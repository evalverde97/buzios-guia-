# Grupo Búzios · Aurya IA

Landing estática preparada a partir del HTML proporcionado. Sin dependencias ni compilación.

## Publicación en Netlify
Importar este repositorio desde GitHub. `netlify.toml` configura `.` como carpeta de publicación; dejar el comando de build vacío.

## Vista local
`python3 -m http.server 8080`

## Alcance
La IA, reservas, cupones y portal del diseño son ilustrativos; este proyecto no incluye backend. El contacto conserva el teléfono y correo del original. La revista no tiene un PDF adjunto: el botón navega a su sección informativa. Las cifras y afirmaciones comerciales se conservan del documento original y no fueron verificadas.

## Cambios
Imágenes extraídas y deduplicadas sin modificar su calidad, enlaces de contacto, metadatos, foco accesible, movimiento reducido y ajustes móviles.
